فایل‌های شما

File Organizer Pro تمام عملیات سازماندهی فایل را به‌صورت محلی (Local) روی دستگاه خودتان انجام می‌دهد. محتوای فایل‌ها، نام فایل‌ها، یا مسیرهای پوشه‌ی شما هرگز به سرور ارسال نمی‌شود.

اطلاعات حساب کاربری

برای استفاده از قابلیت سازماندهی، باید یک حساب با ایمیل بسازید. ایمیل و رمز عبور (به‌صورت هش‌شده) توسط سرویس Supabase Auth نگه‌داری می‌شود.

اطلاعات اشتراک و پرداخت

وضعیت پلن (رایگان/پرو/مکس) و تاریخ انقضای اشتراک شما ذخیره می‌شود تا سرویس درست کار کند. پرداخت‌ها از طریق شبکه‌ی Pi Network انجام می‌شوند؛ ما اطلاعات کیف‌پول یا کلید خصوصی شما را هرگز دریافت یا ذخیره نمی‌کنیم.

آمار مصرف

برای اطمینان از رعایت سقف پلن رایگان، مجموع حجم فایل‌های سازماندهی‌شده (نه خودِ فایل‌ها) با حساب شما ذخیره می‌شود.
